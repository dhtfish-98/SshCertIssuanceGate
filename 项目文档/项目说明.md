# SshCertIssuanceGate：本机 SSH 用户证书签发授权实验

作者：dhtfish98。版本：0.1.0。状态：本地工程验证通过；真实部署与 CVP 资格仍待独立证据。

## 防御边界

自建测试 CA 先登记账户的随机凭据、允许的单一用户 principal 和最长 TTL。每个请求在 SQLite 中绑定账户、Ed25519 请求公钥与截止时间。签发时重新验证凭据、请求归属、公钥、principal、TTL、剩余请求窗口和一次性状态；调用本机 `ssh-keygen` 真正签发 SSH **用户**证书；签发后再次检查时间，原子地写入证书和审计决定。

实验对照中的弱版本仅位于源码包 `tests/weak_baseline.py`，故意忽略 principal 白名单并为 `root` 签发。修复版拒绝相同越权请求，`audit` 表保留 `PRINCIPAL_DENIED`。正式 wheel 只包含 `src/ssh_cert_issuance_gate` 下的三个模块和包元数据。

独立验证器位于 `tests/independent_verify.py`，解析 OpenSSH Ed25519 用户证书字段，核对主体公钥、CA 公钥、精确 principal、有效期和无扩展约束，并让 OpenSSL 3 对证书签名的原始字节做 Ed25519 验签。另调用 `ssh-keygen -L` 检查格式。独立验签并不等于已经部署到真实 `sshd` 或完成登录认证。

## 验收和证据

从仓库根目录运行 `python tools/validate_release.py` 可重建源码、sdist 和隔离安装 wheel 的验证收据。所有生成的密钥、SQLite 文件、临时签名输入都位于 `Build` 临时目录，运行结束删除。`Build` 保留公钥、公开证书、日志、发行包、`validation.json`，以及复查所需的解包暂存和隔离环境；仓库的 `src` 与 `tests` 保留源码，`项目文档` 保留说明。

收据应逐项证明：合法账户获得精确 `alice` principal 和 60 秒有效期的证书；弱版越权 `root` 能签而修复版拒绝并记录审计；跨账户、错凭据、换请求公钥、超长 TTL、过期请求、重放均拒绝；SQLite 重启后状态仍在；同一请求并发只签一次；签名过程中到期也不入库；源码、sdist 和 wheel 中的测试都通过，wheel 不含弱基线。每一条都以 `validation.json` 和对应日志核对，不以此推断外部申请结果。

## 范围限制 / OPEN

- 账户随机凭据由本地可信调用方持有；没有外部身份校验、网络接口或 SSH 私钥持有证明。
- 测试 CA 私钥由实验外部生成并传入；没有硬件密钥托管、轮换、吊销、KRL 或真实 `sshd` 登录验证。
- 自建弱基线只说明同一实验中 principal 授权检查的作用，不能证明 smallstep/certificates 存在漏洞。
- CVP 申请仍需申请人真实授权的同类双用途任务及防护影响证据；本机合成实验不能证明获批。
